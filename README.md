A small program that writes one sentence (193 characters) to `/output/entry.txt`: a pitch for a bizarre startup that sounds ridiculous at first glance but makes sense as a real business — renting strangers' grandmothers to scold grad students into finishing their theses, because a disappointed grandma beats any productivity app, and procrastinators pay for a deadline they can't set themselves.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
